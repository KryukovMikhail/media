# MEDIA — мои книги, фильмы и музыка

Сайт для GitHub Pages: https://kryukovmikhail.github.io/media/

## Структура
- `index.html` — сам сайт (не трогать при пополнении)
- `data/movies.js` — фильмы и сериалы
- `data/books.js` — книги
- `data/music.js` — музыка (позже)

## Как добавить запись
**Через сайт:** нажми ✎ в шапке → «+ Добавить» → заполни → «Сохранить».
Изменения сохраняются в браузере; появится плашка «Скачать movies.js» —
скачай файл и загрузи его в папку `data/` репозитория (Add file → Upload files).

**Вручную:** открой `data/movies.js` на GitHub (✎ Edit) и скопируй любой блок `{ ... }`.

## Поля
| Поле | Что это |
|---|---|
| title / original | название / оригинальное |
| year, director, country, author | метаданные |
| tags | теги: тип, жанр, списки (`любимые`, `посмотреть`, `прочитать`…) |
| my | моя оценка 0–10 |
| kpId / kpRating | ID и рейтинг Кинопоиска (ID — число из kinopoisk.ru/film/**ID**) |
| imdbId / imdbRating | ID и рейтинг IMDb (tt… из imdb.com/title/**tt…**) |
| poster | ссылка на постер (если пусто — берётся с Кинопоиска по ID) |
| description / review | описание / мой отзыв |
| done | когда посмотрел/прочитал |

Записи с тегом `посмотреть` / `прочитать` считаются планами и не входят в среднюю оценку.
